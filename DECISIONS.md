# Decision log

Every architectural decision, with what triggered it and when to revisit. **Superseded
rows are kept deliberately so we do not re-litigate them.** Read this before proposing an
alternative — it may already have been rejected, with a reason.

---

|---|---|---|---|---|
| **V1** | 20 Sep 2026 | **New codebase.** No code is carried in from anywhere | The factory architecture — GuideGraph, arm-don't-press, distillation — wants its own seams. Grafting it onto an existing shape costs more than laying them fresh | **Firm** |
| **V2** | 20 Sep 2026 | **Data and knowledge packs may be imported; nothing else may.** `data/knowledge`, `data/sources`, `data/guides`, the zone and name tables | Facts about TBC are expensive to assemble and cheap to verify. Code is the opposite | **Firm** — provenance in `data/README.md` |
| **V3** | 20 Sep 2026 | **JevRadio is pixel-encoded** — RGB grid, 4 bits/channel, calibration row, checksum plus sequence counter | Density and decode speed, at a robustness level that survives gamma and capture transforms | **Current** — revisit if organisers object to opaque addons; the fallback is legible digits read by a glyph atlas, which costs cells not correctness |
| **V4** | 20 Sep 2026 | **Claude is everything above System 1, over the subscription** (`claude -p`), **not the Anthropic API.** GLM is the cheap bulk rung | Owner has a subscription and no Anthropic key, and wants the ML takeover to be real rather than aspirational. Forces the wean onto the critical path, which is the correct place for it | **Current** — revisit if a hosted key appears, or if subscription limits block a gate |
| **V5** | 20 Sep 2026 | **The GuideGraph is generated from this server's world DB, then verified by walking** | 6,599 quests and 109,358 spawns with exact coordinates are already on disk. Supersedes the hand-authoring mechanism in PLAN §7.6, not its intent |
| **V6** | 20 Sep 2026 | **Retail guide packs are a cross-check, never a source** | Custom servers delete, rename and relevel quests. Diffing pfQuest/RestedXP against the world DB is how those changes announce themselves | **Firm** |
| **V7** | 20 Sep 2026 | **Multi-client input path is deferred**; the architecture keeps it a deployment question | One cursor per Windows session is an OS constraint. Until then: no shared client state, `hid` backends swappable |
| **V8** | 20 Sep 2026 | **Rungs are named for their job, never their supplier** — `coach/`, `teacher/`, not `jev/jev/` or `claude/` | A vendor-named module forces a rename the moment the vendor moves, and that rename touches contracts | **Firm** |
| **V9** | 20 Sep 2026 | **Label by outcome, not by authorship.** Train only on choices graded good at +60 s | Cloning a teacher caps the student at the teacher's error rate, and we have ground truth. Promotes PLAN §12.1's optional bandit to load-bearing | **Firm** — `ARCHITECTURE.md` §2 |
| **V10** | 20 Sep 2026 | **`situation_key` in the schema from commit one** | It is simultaneously the teacher-dedup key, the counterfactual join, the agreement bucket and the answer cache. Unrecoverable if added late | **Firm** — bin widths versioned separately |
| **V11** | 20 Sep 2026 | **The teacher's preferred output is a durable artifact** — skill draft, graph patch, `on_fail` edge — not an immediate action | A decision helps one client once; a skill helps forever. On a rate-limited teacher that compounds. Inverts PLAN §9.2 | **Firm** |
| **V12** | 20 Sep 2026 | **The radio labels the vision heads.** Every `addon_ok` tick logs `(vision_estimate, radio_truth)` for every shared field | Makes fusion confidence measured rather than guessed, and makes addon-off a continuously validated mode rather than a hoped-for one | **Firm** — `ARCHITECTURE.md` §5 |
| **V13** | 20 Sep 2026 | **One source of truth for anything two components must agree on.** Python defines, Lua is generated | Agreement by convention decays silently; agreement by construction cannot | **Firm** — hand-editing `Fields.lua` is a build error |

| **V14** | 20 Sep 2026 | **The teacher's model is pinned, and pinned down: Sonnet, never the CLI default** | An unpinned `claude -p` inherits the user's default, which here is Opus — the scarcest model on the plan and the one the human is using to build with. A farm of ten clients would quietly consume the developer's own capacity. Measured: unpinned calls returned 429 "out of usage credits" while Sonnet and Haiku answered immediately; the *plan* was untouched, only the Opus allocation was spent, and the error message said neither | **Firm** — an explicit model still wins, for escalating a hard postmortem |
| **V15** | 20 Sep 2026 | **Wait for the artifact; discard the stale action** | Measured round trip on a realistic prompt is **52 s** against a 60 s situation bin, so a late answer is the common case. Artifacts describe the *step* and do not go stale; only the fallback action does, and by the time it lands the scripted coach has acted anyway. Discarding whole replies to avoid stale actions would throw away the durable half — which V11 says is the valuable half | **Firm** — `stale_after_s` on the runtime |
| **V16** | 20 Sep 2026 | **Outstanding questions are tracked by the bucket they were asked under** | `situation_key` bins step age, so a step crosses from "fresh" to "slow" at 60 s and its key changes mid-flight. Looking up only the *current* key misses every slow answer, re-asks, and never hits the cache the key exists to enable | **Firm** |

| **V17** | 20 Sep 2026 | **There is no facing API in 2.4.3. Heading is measured, not read** | `GetPlayerFacing` arrived in 3.0; on this client it does not exist, so the field decodes as unknown — confirmed live, and only our own addons reference it while the stock UI does not. Navigation therefore uses **closed-loop turning**: take a heading from a position delta while moving, compute the angle to the target, turn for `angle / turn_rate`, re-measure. Absolute facing is never needed, and a noisy reading costs another iteration rather than a walk into a lake | **Current** — V29 tried to supersede this and did not survive measurement; closed-loop turning is still how this bot aims |
| **V18** | 20 Sep 2026 | **The bot never fights the operator for the desktop** | `SetForegroundWindow` fails from a process that does not own the foreground — measured. `AttachThreadInput` is used so a supervisor can restore a window after a loading screen or a stray alt-tab, but `Hid` refuses to press anything whenever the window is not focused, and that guard is not conditional on it | **Firm** — the guard held on its first live test, refusing rather than typing into the wrong window |

| **V19** | 20 Sep 2026 | **The planner is a standalone Detour sidecar over the server's own mmaps.** `tools/jevpath` links the already-built `libDetour.a` and reads the already-extracted tiles; `MmapQuery` keeps one long-lived process per map | Those tiles are how CMaNGOS walks its own NPCs around Northshire Abbey — the exact problem — and they cost nothing because they were extracted when the server was built. Rejected: **in-process tiles** (no usable Detour binding for Python, and writing one is a project); **CMaNGOS `PathFinder`** (takes a `Unit*` and reaches into the game object model, so it cannot be called standalone — everything it adds over Detour is unit-specific smoothing); **the `.mmap path` GM command** (needs a logged-in character and a chat parser to read its own answer back); **building a second mesh** (a week, to reproduce what is on disk). Long-lived because map 0 is 513 tiles, 2.2 s and 577 MB to load and microseconds to query | **Current** — revisit if a leg needs a route the mesh does not have, which is what `RecordedQuery` is the seam for |
| **V20** | 20 Sep 2026 | **Waypoints are the route, so intermediate arrival is *tight*, not loose** | The obvious choice is wrong. Detour emits waypoints at polygon portals, which around a building come as close as **1.9 yards** apart, so an 8-yard "close enough" radius marked most of a route as already reached: the follower skipped ahead, cut the corner, and walked into the Abbey it had just been routed around — eight legs of nine, failing at the wall the planner existed to avoid | **Firm** — 3 yards, and waypoints closer than that are thinned rather than kept |

| **V21** | 20 Sep 2026 | **A heading is never taken across a turn, and the cruise deadband is 22 degrees** | A pulse arcs the character, so a heading window spanning the pulse measures the arc: the reading overshoots, the error flips sign, and the next tick corrects the other way. Measured: 50 turns in 37 s — a pulse every 0.7 s — on a three-point path a person would walk as two straight lines. Ten degrees is a docking tolerance; with the readout quantising at 0.12 yards and a heading needing 1.5 yards behind it, ten degrees is inside the noise on a long leg. After: **8 turns, 11.6 s, no stucks, no detours** | **Firm** — the weave was the controller, never the mesh |
| **V22** | 20 Sep 2026 | **A blocked planned leg re-queries the planner; it does not detour** | `_detour` is the wall heuristic for walking at a raw node. On a navmesh polyline it is the follower arguing with the planner, and it showed up as three detours on a route already solved. Unstick still runs — a fence is a fence — but the way round a building comes from the mesh, which knows about the door | **Firm** — `to(allow_detour=False)`, `follow(replan=...)` |

| **V23** | 20 Sep 2026 | **The quest log arrives one entry per paint** (`quests.slot` / `quests.count`), replacing a watched-quest field. Schema 2 | 2.4.3 has no "current quest" beyond the watch list and **nothing sets a watch**, so every quest field read as unknown on a live client that had quests in it — and the tracker could not answer "did I accept this?", which is the predicate the whole questing half of the guide rests on. Cycling needs no channel into the addon and keeps it stateless: the decoder reassembles the log from `slot`/`count` over ~2 s at 10 Hz, and `log_hash` says when to discard the assembly | **Current** — `count == 0` is a positive empty log, which is what puts a fresh character on `graph.entry` rather than on whoever is standing nearby |
| **V24** | 20 Sep 2026 | **A character `type_text` cannot send is a failure, not something to skip** | `/` was absent from the key table, so `slash("/reload")` typed **reload** — the addon was never reloaded, a schema bump appeared not to take, and the character announced itself to Northshire. Silent skipping turns a command into a chat message | **Firm** — unsendable characters are recorded and the call returns False |

| **V25** | 20 Sep 2026 | **One frame is never a quest log.** `to_state` returns `None` for any non-empty log; `jev.perceive.questlog.QuestLog` is the only thing that assembles one | The strip cycles one entry per paint, so a frame carries one quest out of `count`. Presenting that as a short log has the tracker find its step's quest absent and fire `QUEST_MISSING` — skipping a live step, twice a second, for as long as the log has more than one entry. Same class as `()` versus `None`, one layer further out. `count == 0` is the single case one frame settles: there are no slots to wait for | **Firm** — `log_hash` discards a half-built assembly rather than mixing two logs |

| **V26** | 20 Sep 2026 | **One locator for every unit on screen**: the selection ring and the nameplate, from one colour-and-components pass. `jev/perceive/units.py` | There is no way to ask 2.4.3 where a unit is, and aiming at a node cannot work because a node is a spawn point and units wander. The ring and plate bracket the model — feet and head — so the midpoint is the torso at any distance, for any unit, with no per-creature knowledge. Fill ratio separates them: a ring is hollow at 0.27, a bar solid at 0.97 | **Both anchors remain required** — measured NPC interactions work, but 22 September wolf frames pair real plates with yellow grass. Ring identity across terrain is not established. The earlier guessed fallback measured 1.27 on one frame and 2.05 on another and clicked Willem's feet |
| **V27** | 20 Sep 2026 | **`target.in_melee` gates nothing that needs interact range** | It is `CheckInteractDistance` index 3 — *duel* range, about eleven yards — while an NPC talks at roughly five. It reads true with the character standing well back, and hours went on right-clicking a model in plain sight and out of reach. Arrival is now the client's own collision: walk forward until the character stops moving | **Firm** — revisit only if a real ~5-yard check can be painted |
| **V28** | 20 Sep 2026 | **Skills get hard caps, and the caps are tested** | The first `Interact` grew a method per failure — preflight, approach, leave_range, turn_to, find_on_screen, locate, a click offset, a fourteen-point sweep — each a patch on the previous symptom. One `/target`, one look, at most one yaw, one click, one confirmation; `tests/test_interact.py` asserts the dead machinery is *absent* | **Firm** — a skill that needs a ninth step needs rewriting, not a ninth step |
| **V29** | 21 Sep 2026 | **Facing is readable in 2.4.3, off the minimap arrow** | The arrow the minimap draws is a `Model`, and `Model:GetFacing()` returns radians (XiconQoo/AVR-TBC, `Core.lua`). The addon polyfills `PLAYER_FACING` over it so `pos.facing` paints as it always claimed to, with **no schema change**. The arrow is matched on its model path, `Interface\Minimap\MinimapArrow`, because the frame name is not guaranteed. **Which object carries the angle is a client setting**: with `rotateMinimap` off the map is north-up and the arrow turns with the player; with it on the map turns and the arrow is pinned pointing up, so `Minimap:GetFacing()` is asked as well and the first to answer wins. This client has `rotateMinimap "1"`. Zero and sign are **measured, never reasoned**: `tools/verify_facing.py` walks forward from several headings and compares the painted value against the direction the character actually moved | **Tried and withdrawn** — measured on this client with `rotateMinimap 0` and a reload, `arrow:GetFacing()` returns **0.0 at every heading**: five walks, direction of travel spread across 160°, painted value unmoved. A constant is worse than nil because a navigator acts on it, so `pos.facing` paints unknown and **V17 stands**. The arrow may not be the model that carries the angle; settling that needs the addon to record what the minimap's children actually are into SavedVariables and read it off disk — client-local, no chat. Asking via `/script` is not an option: it types into the chat box, and a refused keystroke mid-line leaves half a command sitting in Say |
